Sodium View Shake Control（sodium_plugin）  作者：WWZDGqs

在 Sodium 视频设置中新增一组「视角抖动控制」与多项画面增强功能，可自由调节视角抖动强度、镜头特效、玩家高亮、HUD 信息、箱子 ESP 与命中回放。所有功能均通过 Sodium 设置页或 Mod Menu 配置，无需任何命令。

**版本**：1.0.3
**适用游戏版本**：Minecraft 1.21.11（Fabric）
**运行依赖**：Fabric Loader ≥ 0.19.3、Fabric API、Fabric Language Kotlin、Sodium ≥ 0.8.13
**可选依赖**：Mod Menu（用于从模组列表打开设置界面）

功能列表

### 1. 视角晃动
- **视角晃动强度**：控制第一人称视角整体晃动幅度，0% 完全关闭，100% 为原版默认。
- **疾跑抖动**：关闭后疾跑时视角晃动大幅减弱。
- **受击抖动**：关闭后角色受伤时屏幕不再倾斜抖动。

### 2. 镜头特效
- **反胃扭曲**：关闭后吃下河豚等导致的反胃视角扭曲不再出现。
- **药水视场角缩放**：关闭后速度、神龟等药水不再改变视野广角。
- **粒子数量**：控制粒子生成数量百分比。
- **视场角效果**：视野缩放系数，50%–300%。
- **伽马值**：画面亮度调节，1–3000。
- **显示隐身玩家**：让隐身状态的玩家完全可见（仅客户端渲染）。

### 3. 玩家高亮
- **高亮附近玩家**：为范围内其他玩家添加发光轮廓。
- **高亮距离**：高亮生效的半径。
- **高亮颜色**：发光轮廓与名字标签的颜色。

### 4. HUD 增强
- **药水剩余时间**：在状态效果图标旁显示剩余秒数。
- **临期闪烁边框**：药水剩余 ≤10 秒时图标周围闪烁彩色边框。
- **伤害显示条**：在血量与饱食度上方显示你造成的伤害（目标、数值、来源）。
- **爆炸伤害归因**：把末地水晶、重生锚、TNT 等爆炸伤害也算作你的伤害。
- **伤害飘字**：击中实体时，在屏幕中上方飘出该次造成的伤害数字（向上飘动并淡出）。
- **连击计数**：命中敌人累加连击，超过 2.5 秒未命中清零；屏幕右上角显示当前连击与历史最高。
- **投掷物冷却**：手持处于冷却的物品（末影珍珠、雪球、TNT 等）时，屏幕右下角显示剩余冷却进度条与秒数。

### 5. 箱子 ESP
- **启用箱子 ESP**：用半透明彩色方块标出附近箱子、潜影盒与末影箱。
- **搜索范围**：搜索容器的半径。
- **容器类型**：可分别开关箱子、潜影盒、末影箱。

### 6. 命中回放
- **启用受击记录**：记录你受到的每次伤害（数值、时间、来源、死亡信息）。
- **最大记录条数**：保留记录的上限。
- **查看受击回放**：打开记录界面浏览伤害历史与死亡信息。
