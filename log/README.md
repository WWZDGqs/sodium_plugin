Sodium View Shake Control（sodium_plugin）  作者：WWZDGqs

在 Sodium 视频设置中新增一组「视角抖动控制」与多项画面增强功能，可自由调节视角抖动强度、镜头特效、玩家高亮、HUD 信息、箱子 ESP 与命中回放。所有功能均通过 Sodium 设置页或 Mod Menu 配置，无需任何命令。

**版本**：1.0.3
**适用游戏版本**：Minecraft 1.21.11（Fabric）
**运行依赖**：Fabric Loader ≥ 0.19.3、Fabric API、Fabric Language Kotlin、Sodium ≥ 0.8.13
**可选依赖**：Mod Menu（用于从模组列表打开设置界面）

功能列表

1. 视角晃动
**震屏强度**：整体视角抖动强度，0%–100% 可调，统一缩放所有抖动效果。
**疾跑震屏**：开启后，疾跑时镜头产生晃动感。
**受伤震屏**：开启后，受到伤害时镜头产生晃动反馈。

2. 镜头特效（Camera FX）
**恶心晃动**：开启后，处于恶心/中毒等状态时的镜头扭曲效果保留并可被强度控制。
**药水 FOV**：开启后，药水效果会按设定改变视野（FOV）。
**粒子数量**：控制粒子生成比例，0%–100% 可调，降低可提升性能。
**FOV 特效**：视野特效强度，50%–300% 可调，控制药水等引起的 FOV 变化幅度。
**亮度调节**：画面亮度（Gamma）调节，1–3000 可调，等效原版亮度滑块的扩展范围。
**显示隐身玩家**：开启后，对处于隐身状态的玩家也进行渲染。

3. 玩家高亮（Player Highlight）
**高亮开关**：开启后高亮显示其他玩家，便于在混战/人群中分辨。
**高亮范围**：高亮生效的距离范围，8–128 可调。
**高亮颜色**：从预设颜色中选择高亮轮廓颜色。

4. HUD 增强
**药水时间**：在背包/物品栏的药水图标上显示剩余时间。
**药水边框**：为药水图标叠加边框样式，便于快速识别。
**伤害显示**：在屏幕上显示伤害数字，提供即时的命中/受击反馈。
**爆炸署名**：在爆炸效果处显示署名/来源信息。

5. 箱子 ESP
**启用 / 范围**：开启后，在设定范围（8–128）内以彩虹循环变色的线框高亮箱子类方块，且可穿透墙体显示。
**箱子**：开关普通箱子与陷阱箱的高亮。
**潜影盒**：开关潜影盒的高亮。
**末影箱**：开关末影箱的高亮。

### 6. 命中回放（Hit Replay）
**录制开关**：开启后记录命中/战斗相关事件。
**最大记录数**：保留的记录条数上限，10–500 可调。
**查看记录**：打开回放记录界面，浏览已保存的命中记录。
