Sodium View Shake Control（sodium_plugin）  作者：WWZDGqs

在 Sodium 视频设置中新增了视角抖动控制与画面增强，可调节视角抖动强度、镜头特效、玩家高亮、HUD 信息与命中回放。功能通过 Sodium 设置页或 Mod Menu 配置。

**版本**：1.0.4
**适用游戏版本**：Minecraft 1.21.11（Fabric）
**运行依赖**：Fabric Loader ≥ 0.19.3、Fabric API、Fabric Language Kotlin（Kotlin ≥ 2.3.0）、Sodium ≥ 0.8.0
**可选依赖**：Mod Menu（用于从模组列表打开设置界面）

### 1. 视角晃动
- **视角晃动强度**：控制第一人称视角整体晃动幅度，0% 完全关闭，100% 为原版默认。
- **疾跑抖动**：关闭后疾跑时视角晃动大幅减弱。
- **受击抖动**：关闭后角色受伤时屏幕不再倾斜抖动。

### 2. 镜头特效
- **反胃扭曲**：关闭后吃下河豚等导致的反胃视角扭曲不再出现。
- **药水视场角缩放**：关闭后速度、神龟等药水不再改变视野广角。
- **粒子数量**：控制粒子生成数量百分比。
- **视场角效果**：视野缩放系数，50%–300%。
- **伽马值**：画面亮度调节，1–3000。
- **显示隐身玩家**：让隐身状态的玩家完全可见（仅客户端渲染）。

### 3. 玩家高亮
- **高亮附近玩家**：为范围内其他玩家添加发光轮廓。
- **高亮距离**：高亮生效的半径。
- **高亮颜色**：发光轮廓与名字标签的颜色。

### 4. HUD 增强
- **药水剩余时间**：在状态效果图标旁显示剩余秒数。
- **伤害显示条**：在物品栏上方显示你造成的伤害。
- **伤害飘字**：击中实体时，在屏幕中上方飘出该次造成的伤害数字。
- **距离显示**：准星指向实体时，在准星右侧显示你与该实体的距离。

### 5. 命中回放
- **启用受击记录**：记录被其他玩家攻击造成的伤害，含武器、伤害类型、距离与击杀归因
- **最大记录条数**：保留记录的上限。
- **查看 PvP 受击记录**：打开记录界面浏览被其他玩家攻击的伤害历史。

### 6. 自动截图
- **启用自动截图**：开启后，在击杀或死亡瞬间自动保存截图到游戏 `screenshots` 目录。
- **击杀截图**：击杀任意实体时自动截图。
- **死亡截图**：你死亡时自动截图。

### 7. 辅助功能
- **千万别点**：点了崩端
