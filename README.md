Warzone Utils
作者：WWZDGqs

Minecraft 1.21.11 Fabric 客户端模组，PvP 信息显示与镜头效果调节。

适用游戏版本：Minecraft 1.21.11_Fabric_Loader
运行依赖：Fabric Language Kotlin、Sodium-0.8.0 以上
可选依赖：Mod Menu

视角抖动：视角晃动强度、疾跑抖动、受击抖动
镜头特效：反胃扭曲、药水视场角缩放、粒子数量、视场角效果、伽马值、显示隐身玩家
HUD 增强：药水剩余时间、伤害显示条、实时伤害显示、爆炸伤害归因、目标状态显示
受击回放：启用受击记录、最大记录条数、查看受击回放
自动截图：启用自动截图、击杀截图、死亡截图
末影箱预览：末影箱缓存、背包按钮、查看末影箱快照
